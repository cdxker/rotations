# Welcome to Rotations

**Rotations** is a modern music player that reimagines how you curate and organize music. Instead of traditional playlists, Rotations uses **rotations** — personalized music collections that grow as you listen.

## Key Features

  <Card title="Permanent Persistence" icon="music">

  </Card>
  <Card title="Multi-Source" icon="network">

  </Card>
  <Card title="Offline First" icon="wifi-off">

## What Rotations Does

Rotations is built for music lovers who:

- Want to **curate** their own music library from multiple sources
- Need **offline access** to their music collection
- Prefer **import-only** curation over algorithmic recommendations
- Want their music to **persist** across devices and time

## Tech Stack

Rotations is built with modern web technologies:

- **Astro 5** - Meta-framework for fast, content-driven sites
- **React 19** - Interactive UI components
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **TinyBase** - Lightweight data persistence
- **Spotify Web API** - Music streaming integration
